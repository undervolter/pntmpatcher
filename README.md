<h1>pntmPatcher</h1>
Patch kit for Phantom v3
</div>


## Features

- Decrypts the encrypted Phantom binary
- Patches/cracks the executable
- Bypasses the license check
- Disables integrity/anti-tamper checks
- Disables Frida/DLL detection
- Disables watchdog/self-protection functions
- Disables certain parent-process/unhooking checks
- Changes Phantom's branding/OSD text
- Saves the modified/cracked .exe

> [!IMPORTANT]
> This is an education tool for understanding how reverse-engineering works. Do not use it for malicious scenarios.
